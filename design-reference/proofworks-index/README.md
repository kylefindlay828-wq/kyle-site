# Download guide

Upload the entire folder or ZIP to your project workspace.

For Claude Code:
1. Add the bundle to the repository, for example under `/design-reference/proofworks-index/`.
2. Open `claude-code-build-prompt.md`.
3. Copy and paste the full prompt into Claude Code.
4. Tell Claude Code the exact folder path containing the bundle.

Use the JSON/TypeScript data as the source of truth.
Use SVG/PNG only as visual references.
